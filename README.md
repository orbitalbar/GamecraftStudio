# GameCraft Studio – GitHub Pages

## Files
- `index.html` – the website.
- `kep2.png` – the image used in the homepage banner. Keep it in the same folder as `index.html`.

## Set up GitHub Pages
1. Upload `index.html` and `kep2.png` to the same folder in your repository.
2. In your repository, open **Settings → Pages** and select **Deploy from a branch**.
3. Select the `main` branch and the `/(root)` folder, then save.
4. Wait for GitHub Pages to publish the website.

The page includes the Content Creator application form. Visitors can close it with the X button, submit their answers, and see a 10-second countdown before being redirected to the Discord server. They can skip the countdown. The form currently runs in the browser only; responses are not stored or sent to Discord.
